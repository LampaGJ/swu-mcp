# Pairs measurement after the pronoun-defeat fix, 2026-10-30

What this answers: did the grammar change in `9446349` (issue #60, "then defeat it" resolves to the clause's earlier unit target) move the pairs-v1 benchmark, and what did it change in the data?

## TL;DR

Nothing moved on the benchmark. `pnpm verify:pairs` on the rebuilt run `data/runs/2026-10-30` is identical to the 2026-10-17 run in every figure, including all 31 per-row entries. Exactly one card's features changed: "No Glory, Only Results" (`04010043`) now offers `defeat-any-unit` instead of `defeat-self`, and a fresh server lists it as a key-unit answer for Cad Bane / Nevarro City.

## Figures

- Run before: `data/runs/2026-10-17` (code commit `4e75fb0`). Run after: `data/runs/2026-10-30` (code commit `9446349`, originals `mault/data/swu-originals/2026-10-16`, buildHash `3754a885…`).
- Overall: 200 fixture items, 199 still emitted, precision 0.7424 (147/198), recall of labelled-correct pairs 1.0 (147/147). Unchanged.
- Mechanical: 167 items, precision 0.7048 (117/166), recall 1.0. Unchanged.
- Trait-only: 33 items, 32 still emitted, precision 0.9375 (30/32). Unchanged.
- `verify/pair-precision.json` of the two runs is byte-identical apart from the run label and commit.
- `pnpm verify:audit --run data/runs/2026-10-30`: nine checks, all PASS.

## What changed in the data

- `features.json`: one card, `04010043`. Effects `take_control 1 -> any unit, self_defeat 1` became `take_control 1 -> any unit, defeat 1 -> any unit`; tag `offers:defeat-self` became `offers:defeat-any-unit`. Cards offering `defeat-self` went from 18 to 17.
- `synergy/pairs.toon`: 74,530 to 74,636 pairs. The 12 `self-defeat-defeat-watcher` pairs for `04010043` are gone and about 118 `sac-outlet-when-defeated` pairs appear, because the card now offers removal. pairs-v1 holds none of these pairs, so their precision is unmeasured; they carry `status: candidate` like every pairing.
- The six other "defeat it" clauses in the corpus (Saw Gerrera, The Tree Remembers, Salvaged Materials, Nightbrother, Maul) are unchanged.

## Live check

A fresh stdio server from the checkout reports `packageDate 2026-10-30` and, for `meta_answers` with leader Cad Bane (`08010011`) and base Nevarro City (`08010020`), lists "No Glory, Only Results" second among the key-unit answers. Before the fix it was absent from the top 60. The ranking that still puts Display Piece first is issue #65.

Release `data-2026-10-30` (built at `cebc23f`, which also carries #61, #62, #63, #65 and #66) is published and pinned in `src/data-release.json`; a clean `npx -y github:LampaGJ/swu-mcp` downloads it and lists "No Glory, Only Results" first for that call.
